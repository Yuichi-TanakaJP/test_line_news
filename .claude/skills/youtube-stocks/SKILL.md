# youtube-stocks — 株YouTube文字起こし → 銘柄+見立て抽出 → message.txt 生成

株取引YouTube動画の文字起こしから、**言及された銘柄と配信者の見立て**を抽出して
LINE送信用の本文を `message.txt` に生成する。

前提: 文字起こしは**呼び出し側スクリプトが事前に取得**し、`transcript.txt`
(プロフィールの `transcript_file`) に保存済みである。このスキルは取得は行わない。

以下を厳密に実行する。

1. `configs/youtube_stocks.json` を読む。その `extraction` / `sections` / `rules` /
   `format` / `title` / `transcript_file` に従う。
2. `transcript_file`(既定 `transcript.txt`) を読む。**これだけを情報源**とする。
   ファイルが無い／空の場合は、その旨だけを書いた短い `message.txt` を生成して終了する
   (Web検索や憶測で銘柄を補わない)。
3. 文字起こしから銘柄と見立てを抽出する。**rules を厳守**:
   - 雑談(家族・韓国・スパチャ反応・視聴者の利益/億トレ報告・チャンネル宣伝など)は
     除外し、**銘柄と相場の見立てだけ**を拾う。
   - 自動字幕の固有名詞の誤変換を**文脈から補正**する
     (例『太陽油電/太陽遊電』→太陽誘電、『村谷』→村田製作所、『バダナム子』→バンダイナムコ)。
   - **口頭の証券コードは信用しない**。銘柄名から正式コードを判断し、確信が持てなければ
     コードを「要確認」とし、最後の「注意・要確認」セクションにも挙げる。
   - 各銘柄を `extraction.view_labels` のいずれかで分類し、日本株か米国株かで振り分ける。
   - **根拠はできるだけ情報量を多く**する。配信者が触れた要素を可能な限り盛り込む:
     具体的な数値(株価/騰落率/信用倍率/フィボ水準)、テクニカル指標名(移動平均/ボリンジャー
     バンド/MACD/RSI/ゴールデンクロス)、需給(信用買い残・空売り・期日)、ファンダ材料、
     時間軸(当日/週明け/来月)、配信者の言い回し・ニュアンス。根拠は1〜3行に増えてよい。
   - 同じ銘柄への複数言及は1つにまとめる。最大 `extraction.max_stocks` 件。
   - **事実(配信者がこう言った)と主観的見立てを分け**、中立にまとめる(投資助言にしない)。
4. `format` と `sections` に従い、人間が読みやすい日本語テキストで本文を作る。
   - 1行目は `title`。2行目に動画タイトル(分かれば)と配信日。
   - 各セクションは見出し行 `format.section_header_prefix + "N. セクション名"` で始める。
   - 銘柄は「銘柄名(コード) 見立て」を1行目に、根拠を続く行に詳しく書く
     (根拠は情報量重視。他セクションは簡潔に)。
   - 全体 `format.max_chars` 文字以内。末尾に `format.footer` を入れる。
5. 完成した本文を **`message.txt` に上書き保存**する(このファイルのみを書く)。
   送信はしない(送信は呼び出し側 `send_line.py` が行う)。

出力は `message.txt` のみ。余計な説明や他ファイルの変更はしないこと。
